## intro
La classe de Patrick est un platformer à énigmes dans la lignée de jeux comme "Hello Neighbor".
Le jeu se joue en multijoueur local. L'inspiration principale était le jeu "Peak". Nous souhaitions reproduire l'ambiance des parties de jeux vidéo à plusieurs dans notre salon.
Au sein de l'équipe nous déplorons le fait que l'industrie du jeu vidéo privilégie des expériences solo ultra-réaliste ou des jeux en ligne compétitif.
